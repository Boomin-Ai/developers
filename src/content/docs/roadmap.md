## Live now

- `@boomin/connect` browser SDK and `@boomin/cli` CLI.
- Account-first Creator Connect.
- Email OTP before Instagram OAuth.
- Pending approval and admin approve/reject.
- Scoped platform tokens.
- CLI token management and smoke tests.
- OpenAPI docs for current Connect and Platform APIs.

## Next

- Hosted customer portals on custom domains.
- Google auth for creator portal login.
- Campaign CRUD polish in public APIs.
- Program benefits and entitlements.
- Webhook management docs and delivery logs.
- More Platform API resource families behind `api.boomin.ai`.

## Principle

Programs stay durable. Campaigns activate the program. Benefits and requirements sit on top of program membership.
